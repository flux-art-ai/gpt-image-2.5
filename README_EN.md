## Make your first image

1. Open the workspace and follow the account sign-in prompts.
2. Confirm that the selected model is **GPT Image 2.5 Flare** or **GPT Image 2.5 Sunburst**, not a similarly named older version.
3. Choose image generation for a text brief, or image editing for an authorized reference.
4. Specify the subject, composition, lighting and exclusions. Select quality and dimensions, then review the displayed cost before submitting.
5. Inspect the output at useful viewing size. For an edit, compare the result against the original before using it in another round.

A free-trial message does not guarantee a fixed number of GPT Image 2.5 generations. Current access, pricing and account benefits are shown on the official site.

## Flare or Sunburst?

Flare is positioned for quick everyday creative exploration. Sunburst focuses on precise editing. Both support generation and editing: this is a starting-point distinction, not a claim that only one model can perform a task.

For a fair practical comparison, use the same reference, prompt, dimensions and quality. Judge the requested change, preserved details, text and composition. Do not compare a low-quality draft against a higher-quality final and attribute every difference to the model.

## A ready-to-use prompt

> A clear glass teapot containing pale golden tea on a light gray stone surface. Soft window light from the upper right. Horizontal composition with the teapot on the right and clean empty space on the left. No text, logos or additional tableware.

For an authorized product reference:

> Preserve the teapot's silhouette, lid, spout, handle and camera angle. Replace only the background with a light wooden table under soft window light. Add a natural contact shadow. Do not alter the product color or add packaging or text.

These prompts are examples, not benchmark results. Check product geometry, labels and material details yourself.

## FAQ

**Q: Do I need to install this repository?**

No. Open the [Flux Art workspace](https://flux-art.cn/en/models/gpt-image-2-5) in your browser. This repository contains documentation, not a local model runtime.

**Q: Is this an OpenAI repository?**

No. Flux Art maintains it. OpenAI is the model developer, while Flux Art operates the platform described here.

**Q: Can I edit an existing image?**

Yes. Use image editing with an authorized reference, describe the intended change and what must stay unchanged, then inspect the result. An instruction to preserve a detail is not a guarantee that it will be preserved.

**Q: Does online availability prove the same model is available through Flux Art OpenAPI?**

No. Verify the current API catalog and request documentation independently. Web labels and upstream API model IDs are not interchangeable.

**Q: Can I use the output immediately in a product listing?**

Review product accuracy, rights to the input materials, text and the destination platform's current requirements first. A generated image does not establish actual fit, performance or marketplace approval.
